\section{Limitations}
\begin{itemize}
    \item Sample size and number of events.
    \item Single centre, no external validation.
    \item CFD assumptions (rigid wall, Newtonian fluid, boundary conditions); segmentation.
    \item Conservative effect of using a fixed score $S_B$.
    \item Q2: few patients also for unsupervised training; $\mathbf{Z}$ may only recover $\mathbf{Hd}$.
    \item Q2: Euclidean neighbourhoods of PointNet++; design choices (latent size, $k$, alignment); cycle-averaged indices.
\end{itemize}
